# Curated seed list of popular Swift packages for typosquat detection.
#
# IDENTITY: SE-0292 `scope.name`, lowercased — the exact string
# core/formats/swift/resolver.go's NormalizeIdentifier puts in
# PackageCoordinate.Name, which is what the detector is called with. For a
# git-hosted package the scope is the GitHub owner and the name is the repo,
# so github.com/apple/swift-nio is `apple.swift-nio`. A bare repo name would
# never match a real coordinate and must not be used here.
#
# Source: the intersection of
#   (a) SwiftPackageIndex/PackageList packages.json — the canonical list of
#       ~11,600 registered Swift Package Manager packages, and
#   (b) the GitHub search API, language:Swift stars:>200, ranked by stars.
# Snapshot taken 2026-08-25: 332 packages.
#
# WHY THE INTERSECTION. (a) alone is alphabetical and unranked — 11,600
# entries would balloon the BK-tree and put a near neighbour beside almost
# every real name. (b) alone contains Swift *applications* that are not SPM
# packages and can never be a Swift coordinate. Intersecting keeps only real
# packages and gives each one a rank.
#
# WHY STARS AND NOT DOWNLOADS. Neither the Swift Package Index nor a Swift
# Package Registry publishes a download-ranked top-N; SPM resolves straight
# from git for most packages, so no counter exists to read. Stars are the
# only public popularity signal that covers the ecosystem. Stated plainly
# because it is weaker than the download ranks npm/PyPI seeds use.
#
# DETERMINISM. Rank is stars-descending with a lowercase-lexicographic
# tie-break, computed once at generation time and frozen into line order —
# the same discipline fetchNPM applies to npm's popularity score (sort by
# score, then by a stable secondary key, never by map or arrival order).
# Nothing is ranked at read time.
#
# Format:
#   - Blank lines and lines starting with '#' are ignored.
#   - One `scope.name` per line; LINE ORDER IS RANK (line 1 = rank 1).
#
# Refresh cadence: hand-refreshed out-of-band, same posture as
# seeds/go_top.txt and seeds/cocoapods_top.txt.
